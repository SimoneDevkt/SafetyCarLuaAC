Race Control - Safety Car

Public static assets for the Assetto Corsa CSP online-script prototype.

  • Online Lua script
  • Safety Car deployed sound (WAV)
  • Safety Car lights off sound (WAV)
  • Generated ACSM extra-options snippet

Open extra_options.ini and copy its contents to your server's CSP Extra Options. The Lua script references the two audio files using the GitHub Pages URL configured at build time.

Testing prototype: Online events are not server-authoritative; the client script is not a secure competitive race-control enforcement system.
